# Design System Library

A framework-agnostic component library built with Lit web components and TypeScript. Use it directly in HTML or
through Lit, React, Vue, and Angular.

The library provides reusable components, design tokens, accessible interaction patterns, and typed React wrappers.

Source code: [GitHub repository](https://github.com/jsekulowicz/design-system-library)

## Quick start

Install the token and component packages with your preferred package manager.

### pnpm

```sh
pnpm add @jsekulowicz/ds-tokens @jsekulowicz/ds-components
```

### npm

```sh
npm install @jsekulowicz/ds-tokens @jsekulowicz/ds-components
```

Import the default theme and register only the components you use at your application entry point.

```ts
import '@jsekulowicz/ds-tokens/theme-default.css';
import '@jsekulowicz/ds-components/button/define';
```

Registered components work like native HTML elements.

```html
<ds-button variant="primary">Ship it</ds-button>
```

Continue with [Framework usage](?path=/docs/framework-usage--docs) for Lit, React, Vue, Angular, and plain JavaScript
integration patterns.

## Principles

- **Tokens are the contract.** Components never hardcode values. Consumers restyle by overriding semantic tokens.
- **Container-first responsiveness.** An atom reshapes to its slot, not the viewport. Templates own viewport logic.
- **Native platform, augmented.** Form controls implement `ElementInternals` - they submit, validate, and reset like native inputs.
- **Actions start where work starts.** Form and card actions align left on tablet and desktop, then align right on mobile where thumb reach and stacked content matter more.
- **Tree-shake by default.** Subpath imports (`@jsekulowicz/ds-components/button`) bring only what you use. CSS rides with JS via Constructable Stylesheets.
- **A11y is not a toggle.** Every interactive atom ships with role, ARIA state, keyboard interaction, and focus-visible styling verified by axe-core.

## Atomic hierarchy

Atoms → Molecules → Organisms → Templates → Pages. Each layer composes the ones below without leaking implementation.
